# EX-02: WriteAsync と Dispose の競合

## 学習目標
非同期 I/O、Task のライフサイクル、Safety と原子性を学ぶ。

## 課題
WriteAsync と解放の競合をモデル化し、Close 完了後に管理対象の送信 Task が残らない契約を考える。不正モデルで TLC の反例を調べる。書き込みの成功は保証しない。

## 検証と境界
対象とする C# テスト、TLC、Lean を演習時に選び、仮定と未検証範囲を記録する。抽象モデルは .NET や C# 実装自体の証明ではない。
