# EX-06: 複数クライアントと Task 管理

## 学習目標
複数 Accept、ConcurrentDictionary、Session、Task 追跡と Shutdown を学ぶ。

## 課題
複数クライアントとの通信を実装し、Stop 完了時の管理対象 Session と Task の契約を定める。コレクション単体の安全性と複数操作にまたがる不変条件を区別する。
